## Non-author read (2026-10-06)

Every key, letter and value confirmed by the reader. Eight findings about entering programs, all
taken, the screens they needed probed first (keyrun --sequence, 867ddd5) and now quoted:

- **Reopening program entry:** probed. Straight after leaving it, it reopens at F's last line
  (F006 RTN); **after a program has run, at the top (PRGM TOP)** - my first rebuilt vector assumed
  the former and the runner refused it (G01A: expected F006, got TOP). The lesson says what happens
  in its own order: G goes in at the top, F untouched (f(5) still 13).
- **Fixing a mistake:** probed. The backspace key deletes the line showing and steps back
  (K005 + to K004 3); a label used twice is refused with DUPLICAT.LBL, and C clears it, F unchanged.
  Both taught with quotes (M01-M03, D01-D02).
- RTN and leaving program entry split, with F006 RTN quoted; PRGM leaving the status band said.
- XEQ with no equation showing waits for a label: XEQ _ quoted (F02A); LBL _ quoted (F01L).
- H's key moved into the exercise; how long programs last said ("until you clear them", with E02
  using G again); ·33 explained (the program runs as 33s mode even if the mode changes: decision 45);
  the intro's "two keys" claim given its stack caveat.
