# eq-04 rearranging a formula: key vectors (the firmware's format). Every example is ours. Each starts MODE33
# FIX4 (the lesson's setup). CASSOLVE:v is CAS ▸ SOLVE v (unit 048; letters as coefficients from CAS 038, firmware
# 99a62eb). %CASREP is the report's rows joined by ";_", %CASROW the row the cursor is on; ENTER on an answer row
# reads each condition row at the stored values first (abacus #13771): CONDITION FAILS places nothing.
# From before
EQ4F1 | from before: W from A = L x W, A = 36, L = 4, typed | MODE33 FIX4 9 | X=9
EQ4F1W | its working | MODE33 FIX4 36 ENTER 4 / | X=9
EQ4F1A | slip: multiplied | MODE33 FIX4 36 ENTER 4 * | X=144
EQ4F2 | from before: (35 - 5) / 6, typed | MODE33 FIX4 5 | X=5
EQ4F2W | its working | MODE33 FIX4 35 ENTER 5 - 6 / | X=5
EQ4F2A | slip: 35 - 5 / 6 | MODE33 FIX4 35 ENTER 5 ENTER 6 / - | X=34.16666666666666666666666666666667
# V = I x R for R, and its report
C01 | V = I x R, Casimir's SOLVE R: the report, its status row | MODE33 FIX4 EQN RCL:V = RCL:I * RCL:R ENTER CASSOLVE:R | %CASREP=SOLVED:_R=V÷I;_I≠0 %CASROW=SOLVED
C02 | continues C01: down to the answer | MODE33 FIX4 EQN RCL:V = RCL:I * RCL:R ENTER CASSOLVE:R SST | %CASROW=R=V÷I
C03 | continues C02: down to its row | MODE33 FIX4 EQN RCL:V = RCL:I * RCL:R ENTER CASSOLVE:R SST SST | %CASROW=I≠0
K01 | continues C03: C C, then V = 12 and I = 3 stored | MODE33 FIX4 EQN RCL:V = RCL:I * RCL:R ENTER CASSOLVE:R SST SST C C 12 STO:V 3 STO:I | @V=12 @I=3 %CASREP=none
K02 | continues K01: SOLVE R again, ENTER on the answer: 12 / 3 | MODE33 FIX4 EQN RCL:V = RCL:I * RCL:R ENTER CASSOLVE:R SST SST C C 12 STO:V 3 STO:I EQN CASSOLVE:R SST ENTER | X=4 %CASREP=none
K03 | continues K02: I = 0, and ENTER finds I≠0 fails | MODE33 FIX4 EQN RCL:V = RCL:I * RCL:R ENTER CASSOLVE:R SST SST C C 12 STO:V 3 STO:I EQN CASSOLVE:R SST ENTER 0 STO:I EQN CASSOLVE:R SST ENTER | ERR %ERRMSG=CONDITION_FAILS %CASROW=I≠0
K04 | continues K03: C clears the message, the failing row shown | MODE33 FIX4 EQN RCL:V = RCL:I * RCL:R ENTER CASSOLVE:R SST SST C C 12 STO:V 3 STO:I EQN CASSOLVE:R SST ENTER 0 STO:I EQN CASSOLVE:R SST ENTER C | ERR %CASROW=I≠0
K05 | continues K04: C C closes the report and the list | MODE33 FIX4 EQN RCL:V = RCL:I * RCL:R ENTER CASSOLVE:R SST SST C C 12 STO:V 3 STO:I EQN CASSOLVE:R SST ENTER 0 STO:I EQN CASSOLVE:R SST ENTER C C C | ERR %CASREP=none
# C = 2 pi R for R: no row
N01 | C = 2 x pi x R, SOLVE R | MODE33 FIX4 EQN RCL:C = 2 * PI * RCL:R ENTER CASSOLVE:R | %CASREP=SOLVED:_R=C÷2÷π %CASROW=SOLVED
N02 | continues N01: the answer | MODE33 FIX4 EQN RCL:C = 2 * PI * RCL:R ENTER CASSOLVE:R SST | %CASROW=R=C÷2÷π
N03 | continues N02: no row after it, back to the status | MODE33 FIX4 EQN RCL:C = 2 * PI * RCL:R ENTER CASSOLVE:R SST SST | %CASROW=SOLVED
# F = 1.8 C + 32 for C: another form, checked at F = 212
F01 | continues N03: C C, F = 212 stored | MODE33 FIX4 EQN RCL:C = 2 * PI * RCL:R ENTER CASSOLVE:R SST SST C C 212 STO:F | @F=212 %CASREP=none
F02 | continues F01: SOLVE C, down to the answer | MODE33 FIX4 EQN RCL:C = 2 * PI * RCL:R ENTER CASSOLVE:R SST SST C C 212 STO:F EQN RCL:F = 1.8 * RCL:C + 32 ENTER CASSOLVE:C SST | %CASREP=SOLVED:_C=5×F÷9-160÷9 %CASROW=C=5×F÷9-160÷9
F03 | continues F02: ENTER at F = 212 | MODE33 FIX4 EQN RCL:C = 2 * PI * RCL:R ENTER CASSOLVE:R SST SST C C 212 STO:F EQN RCL:F = 1.8 * RCL:C + 32 ENTER CASSOLVE:C SST ENTER | X=100 %CASREP=none
# x^2 = A: declined
W01 | continues F03: x^2 = A for x, COEF NOT NUMERIC | MODE33 FIX4 EQN RCL:C = 2 * PI * RCL:R ENTER CASSOLVE:R SST SST C C 212 STO:F EQN RCL:F = 1.8 * RCL:C + 32 ENTER CASSOLVE:C SST ENTER EQN RCL:X POW 2 = RCL:A ENTER CASSOLVE:X | ERR %ERRMSG=COEF_NOT_NUMERIC %CASREP=none
W02 | continues W01: C C | MODE33 FIX4 EQN RCL:C = 2 * PI * RCL:R ENTER CASSOLVE:R SST SST C C 212 STO:F EQN RCL:F = 1.8 * RCL:C + 32 ENTER CASSOLVE:C SST ENTER EQN RCL:X POW 2 = RCL:A ENTER CASSOLVE:X C C | ERR %CASREP=none
