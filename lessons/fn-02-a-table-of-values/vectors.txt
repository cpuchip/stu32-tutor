# fn-02 a table of values: key vectors (the firmware's format). Every example is ours. Each starts
# MODE33 FIX4 (the lesson's setup). One chain: programs Q and T are entered once.
Q01A | program Q: q(x) = x^2 - 4x + 3, entered up to its RTN (Q011) | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN | %LINES=11
Q01 | continues Q01A: program entry off | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM | %LINES=11
Q02 | continues Q01: q(2) = 4 - 8 + 3, with 2 left in Y | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q | X=-1 Y=2
T01A | continues Q02: program T starts: the counter 0.004 in I | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I | %LINES=14
T01B | continues T01A: the loop U: RCL I, IP, XEQ Q, R/S, ISG I, GTO U; then RTN (U008) | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN | %LINES=22
T01 | continues T01B: program entry off | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM | %LINES=22
T02 | continues T01: XEQ T stops at the first row: x = 0, q = 3 | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T | X=3 Y=0
T03 | continues T02: R/S: x = 1, q = 0 | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T RS | X=0 Y=1
T04 | continues T03: x = 2, q = -1 | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T RS RS | X=-1 Y=2
T05 | continues T04: x = 3, q = 0 | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T RS RS RS | X=0 Y=3
T06 | continues T05: x = 4, q = 3 | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T RS RS RS RS | X=3 Y=4
T07 | continues T06: ISG passes 4, so GTO is skipped and the program ends | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T RS RS RS RS RS | X=3 Y=4 %STOP=DONE
G01 | continues T07: q(1.5), between the rows | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T RS RS RS RS RS 1.5 XEQ:Q | X=-0.75
G02 | continues G01: q(2.5), the mirror of 1.5 about 2 | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T RS RS RS RS RS 1.5 XEQ:Q 2.5 XEQ:Q | X=-0.75
E01 | exercise 1, continues G02: q(1) = 0 checked | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T RS RS RS RS RS 1.5 XEQ:Q 2.5 XEQ:Q 1 XEQ:Q | X=0
E02 | exercise 2, continues E01: q(5) = 25 - 20 + 3 | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T RS RS RS RS RS 1.5 XEQ:Q 2.5 XEQ:Q 1 XEQ:Q 5 XEQ:Q | X=8
E03 | exercise 3, continues E02: a new counter 2.006, started at U | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T RS RS RS RS RS 1.5 XEQ:Q 2.5 XEQ:Q 1 XEQ:Q 5 XEQ:Q 2.006 STO:I XEQ:U | X=-1 Y=2
E03B | continues E03: four more rows, to x = 6 | MODE33 FIX4 PRGM LBL:Q ENTER ENTER SQ XY 4 * - 3 + RTN PRGM 2 XEQ:Q PRGM LBL:T 0.004 STO:I LBL:U RCL:I IP XEQ:Q RS ISG:I GTO:U RTN PRGM XEQ:T RS RS RS RS RS 1.5 XEQ:Q 2.5 XEQ:Q 1 XEQ:Q 5 XEQ:Q 2.006 STO:I XEQ:U RS RS RS RS | X=15 Y=6
B02@STU | STU: q as an expression in the equation list | MODE33 FIX4 EQN RCL:X POW 2 - 4 * RCL:X + 3 ENTER | %EQ=X^2-4×X+3
B03@STU | continues B02: EQN off, then START 0 (the step is 1 by default) | MODE33 FIX4 EQN RCL:X POW 2 - 4 * RCL:X + 3 ENTER EQN 0 TSTART | X=0 %TABLE=0
B04@STU | continues B03: GO: the row x = 0 | MODE33 FIX4 EQN RCL:X POW 2 - 4 * RCL:X + 3 ENTER EQN 0 TSTART TABLE | %TABLE=1 %TK=0 %TX=0 %TY=3
B05@STU | continues B04: down a row: x = 1 | MODE33 FIX4 EQN RCL:X POW 2 - 4 * RCL:X + 3 ENTER EQN 0 TSTART TABLE TDOWN | %TK=1 %TX=1 %TY=0
B06@STU | continues B05: down three more: x = 4 | MODE33 FIX4 EQN RCL:X POW 2 - 4 * RCL:X + 3 ENTER EQN 0 TSTART TABLE TDOWN TDOWN TDOWN TDOWN | %TK=4 %TX=4 %TY=3
B07@STU | continues B06: ENTER copies the row's q(x) to X and leaves | MODE33 FIX4 EQN RCL:X POW 2 - 4 * RCL:X + 3 ENTER EQN 0 TSTART TABLE TDOWN TDOWN TDOWN TDOWN ENTER | X=3 %TABLE=0
W01@STU | continues B07: the window: XMIN -2, XMAX 5.98 (column 200 at x = 2) | MODE33 FIX4 EQN RCL:X POW 2 - 4 * RCL:X + 3 ENTER EQN 0 TSTART TABLE TDOWN TDOWN TDOWN TDOWN ENTER 2 CHS XMIN 5.98 XMAX | X=5.98 %GRAPH=0
W02@STU | continues W01: GO: Y fitted to -1.8 .. 15.8; the trace at column 200, x = 2 | MODE33 FIX4 EQN RCL:X POW 2 - 4 * RCL:X + 3 ENTER EQN 0 TSTART TABLE TDOWN TDOWN TDOWN TDOWN ENTER 2 CHS XMIN 5.98 XMAX GRAPH | %GRAPH=1 %GCUR=200 %GWIN=-1.8,15.8 %GX:200=2 %GY:200=-1
W03@STU | continues W02: one column right: x = 2.02 | MODE33 FIX4 EQN RCL:X POW 2 - 4 * RCL:X + 3 ENTER EQN 0 TSTART TABLE TDOWN TDOWN TDOWN TDOWN ENTER 2 CHS XMIN 5.98 XMAX GRAPH GRIGHT | %GCUR=201 %GX:201=2.02 %GY:201=-0.9996
W04@STU | continues W03: two columns left: x = 1.98, the same height | MODE33 FIX4 EQN RCL:X POW 2 - 4 * RCL:X + 3 ENTER EQN 0 TSTART TABLE TDOWN TDOWN TDOWN TDOWN ENTER 2 CHS XMIN 5.98 XMAX GRAPH GRIGHT GLEFT GLEFT | %GCUR=199 %GX:199=1.98 %GY:199=-0.9996
W05@STU | continues W04: ENTER copies the traced value to X and leaves | MODE33 FIX4 EQN RCL:X POW 2 - 4 * RCL:X + 3 ENTER EQN 0 TSTART TABLE TDOWN TDOWN TDOWN TDOWN ENTER 2 CHS XMIN 5.98 XMAX GRAPH GRIGHT GLEFT GLEFT ENTER | X=-0.9996 %GRAPH=0
